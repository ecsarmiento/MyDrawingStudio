# 🎨 MyDrawingStudio — Arts Studio Drawing Simulation

A browser-based drawing studio! Draw, erase, pick colors, adjust brush size & opacity, and download your artwork instantly.

## ✨ Features
- Real-time smooth drawing
- Custom color picker 🎨
- Adjustable brush size & opacity
- Eraser tool
- One-click PNG download
- Works on desktop, tablets & phones (touch support)
- Fully responsive design

## 🚀 Live Demo
👉 https://ecsarmiento.github.io/MyDrawingStudio/

## 📂 How to Use
1. Select brush or eraser
2. Pick your color and adjust size
3. Draw on the canvas
4. Click **💾 Download Image** to save your work
5. Click **🗑️ Clear** to start over

## 🛠️ Run Locally
Just open `index.html` in any modern web browser — no server needed!

## 📝 Tech Stack
- HTML5 Canvas
- CSS3
- Vanilla JavaScript
- *Note: PHP save feature removed for GitHub Pages compatibility — works fully with local PHP hosting*
